## What is ASTRA?

ASTRA is a full-featured FiveM roleplay server built for immersive gameplay and a seamless player experience. It features custom jobs, vehicles, housing, inventory, and roleplay systems, all designed to create a realistic and engaging world for its community.
---

## Core Stack

| Resource | Purpose |
|----------|---------|
| `astra-core` | Framework foundation — middleware, callbacks, routing, player lifecycle |
| `ox_inventory` | Slot-based inventory with ASTRA bridge |
| `astra-characters` | Character creation and management |
| `astra-vehicles` | Vehicle ownership, garages, keys |
| `astra-hud` | HUD, notifications, progress bars |
| `astra-mdt` | Police MDT |
| `astra-jobs` | Job system — fishing, mining, and more |
